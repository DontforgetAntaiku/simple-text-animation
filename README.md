# Simple Text Animation

Simple text animation. Can be linked with different platforms.

## Installation

Clone the repository:

```bash
git clone https://github.com/DontforgetAntaiku/simple-text-animation.git
cd simple-text-animation
```

**You don't need to install any dependencies**

## Usage

Run the script with Python3:

```python
python main.py
```
